# Aspro Parks — concepto de rediseño web

Propuesta de rediseño de la web de Aspro Parks, hecha como ejercicio de diseño y marketing. **No es una web oficial ni tiene relación con Aspro Parks.**

## Páginas

| Página | Qué incluye |
|---|---|
| `index.html` | Portada interactiva: eliges el plan (agua, animales, acuarios, atracciones) y cambian colores, titular y mensaje |
| `parques.html` | Buscador de los 43 parques del grupo con filtros por tipo y país, y ficha de cada parque |
| `vivelo.html` | Simulador en primera persona (tobogán, montaña rusa y túnel de acuario) en canvas 2D |
| `club.html` | Propuesta de programa de fidelidad: pasaporte de temporada con puntos, sellos, niveles y recompensas |
| `fundacion.html` | Fundación Aspro Natura y compromisos del grupo |
| `eventos.html` | Eventos corporativos con formulario de ejemplo (no envía datos) |
| `noticias.html` | Noticias publicadas por el grupo |
| `partners.html` | Programa de partners |

## Cómo verla

Es HTML, CSS y JavaScript sin dependencias ni compilación. Abre `index.html` en el navegador, o activa GitHub Pages en *Settings → Pages* (rama `main`, carpeta raíz).

## Notas

- El listado de parques sale de las páginas públicas del grupo (octubre de 2026) y conviene revisarlo.
- Fotos, vídeos, logos, precios, horarios y algunas cifras están marcados como `[huecos]` para completar con material real.
- Las recompensas y la mecánica del Club son una propuesta, no un programa existente.
